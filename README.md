GTA 6 Mini — Kota Top-Down adalah game kota 2D dari atas:
pemain berjalan kaki menyusuri jalan, bisa naik mobil,
menghadapi lalu lintas dan pejalan kaki yang ramai,
dikejar polisi saat wanted naik, lalu menyelesaikan
misi antar paket di seluruh penjuru kota sambil
memantau posisi lewat minimap. Semua progres
tersimpan otomatis, jadi permainan bisa dilanjutkan
kapan saja tanpa kehilangan misi yang sudah selesai.

## Cara Main

- Buka `game/index.html` di browser desktop.
- Tidak butuh network atau server; cukup buka file-nya langsung.
- **WASD** — bergerak / mengemudi.
- **E** — keluar dari mobil.
- Dekati mobil lalu masuk untuk mengemudi.
- Antar paket ke titik hijau untuk menyelesaikan misi.
- Hindari polisi saat wanted naik, atau kabur sampai aman.
- Perhatikan minimap untuk posisi pemain, misi, dan polisi.
