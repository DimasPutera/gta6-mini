Game kota 2D top-down: jalan kaki, naik mobil, lalu lintas hidup, pejalan kaki,
polisi dengan level wanted, misi antar paket, minimap, dan simpan progres otomatis.

## Fitur

- Jalan kaki dan naik mobil (WASD / panah, Spasi rem, E masuk mobil)
- Lalu lintas dan pejalan kaki yang bergerak di jalan kota
- Polisi dan sistem wanted: makin banyak bintang, makin agresif kejaran
- Misi antar paket: ambil paket, antar ke tujuan sebelum waktu habis
- Minimap kota 200x200 di sudut layar
- Simpan progres otomatis di localStorage

## Cara jalan

1. Buka `game/index.html` di browser desktop.
2. Tanpa network — semua aset lokal, tinggal klik `#start`.
3. Main: jalan kaki, naik mobil dengan E, hindari polisi.

## Kontrol

| Tombol | Aksi |
| ------ | ---- |
| WASD / panah | Jalan & nyetir |
| Spasi | Rem |
| E | Masuk / keluar mobil |
