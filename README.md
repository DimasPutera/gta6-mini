![Rank](https://make.fun/badge/gta6-01/DimasPutera/gta6-mini/rank.svg)
![Reward](https://make.fun/badge/gta6-01/DimasPutera/gta6-mini/reward.svg)

Game kota 2D top-down yang terinspirasi GTA 6: jelajahi kota mini, jalan kaki atau naik mobil.

## Fitur

- Jalan kaki dan naik mobil keliling kota.
- Lalu lintas hidup: mobil dan pejalan kaki bergerak di jalan.
- Polisi dan sistem wanted: kejar-kejaran makin panas kalau berulah.
- Misi antar paket: ambil paket, antar ke tujuan, kumpulkan hadiah.
- Minimap untuk navigasi cepat ke seluruh penjuru kota.
- Simpan progres: lanjutkan permainan dari tempat terakhir berhenti.

## Cara Main

1. Buka `game/index.html` di browser desktop.
2. Tanpa network — semua berjalan lokal di browser.
3. WASD / panah untuk bergerak, E untuk masuk dan keluar mobil.
4. Ikuti penanda misi di minimap untuk antar paket.
